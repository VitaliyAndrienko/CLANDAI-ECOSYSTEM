КАК РАЗВЕРНУТЬ И ЗАПУСТИТЬ P2F NETWORK
====================================================================================

СОСТАВ КОМПЛЕКТА
------------------------------------------------------------------------------------
код/                     исходный код блокчейна и инструменты запуска
  chain/                 Go-модуль блокчейна (app, cmd/p2fd, x/p2f/* модули)
  scripts/               сборка генезиса и локальная сеть 4 валидаторов
  third_party/cosmos-db  локальный форк базы данных с исправлением рестарта
  docs/                  план и журнал работ
  bin/p2fd.exe           готовый бинарь демона (Windows, Go 1.23)

ПРИМЕЧАНИЕ О ПУТЯХ
------------------------------------------------------------------------------------
Все скрипты определяют корень проекта по своему расположению — папку «код»
можно скопировать в любое место, пути правятся автоматически.

ТРЕБОВАНИЯ
------------------------------------------------------------------------------------
- Windows 10/11, PowerShell 5.1;
- Go 1.23 (портативный или системный);
- доступ в интернет для первой загрузки Go-зависимостей (или готовый кэш
  модулей);
- 2 ГБ свободного места.

ЗАПУСК ЗА 4 ШАГА
------------------------------------------------------------------------------------
1) Скачать Go 1.23 и положить в  код\.toolchain\go  (или поставить системный
   Go и поправить пути в scripts\env.ps1).

2) Собрать демон:
       powershell
       . .\scripts\env.ps1
       cd chain
       go build -o ..\bin\p2fd.exe .\cmd\p2fd

   (Если интернет недоступен — использовать готовый bin\p2fd.exe из
   комплекта.)

3) Инициализировать локальную сеть из 4 валидаторов:
       powershell -File scripts\localnet.ps1 -Action init

4) Запустить сеть:
       powershell -File scripts\localnet.ps1 -Action start
       powershell -File scripts\localnet.ps1 -Action status

   Порт узла N: P2P 16656+10N, RPC 16657+10N, REST API 1317.

ПРОВЕРКА, ЧТО СЕТЬ ЖИВА
------------------------------------------------------------------------------------
- статус:  scripts\localnet.ps1 -Action status  -> 4 узла, одинаковый app hash;
- балансы: http://127.0.0.1:1317/cosmos/bank/v1beta1/balances/<адрес>
- события майнинга/газа/сложности в каждом блоке:
      bin\p2fd.exe query block-results 3 --node tcp://127.0.0.1:16657

ДЕМОНСТРАЦИЯ MVP ЧЕРЕЗ CLI (проверено на живой сети)
------------------------------------------------------------------------------------
Ключи валидаторов лежат в localnet\build (keyring test, имена validator0..3).
Примеры (от имени validator0):

1. Выпустить свою монету:
   bin\p2fd.exe tx p2fcoin create-coin umoon Moon 1000000 400000 ^
     --from validator0 --keyring-backend test --home localnet\build ^
     --node tcp://127.0.0.1:16657 --chain-id p2f-shard-0 ^
     --gas 200000 --fees 0up2f --yes -b sync

2. Создать пул ucland/up2f и обменять:
   bin\p2fd.exe tx p2famm create-pool ucland up2f 10000 10000 --fee-bps 30 ...(флаги как выше)
   bin\p2fd.exe tx p2famm swap 1 up2f 1000 900 ...(флаги как выше)

3. Анонимный перевод (публичных событий не будет — проверить
   query tx <txhash>: есть только p2f.privacy.v1.EventAnonymousSend):
   bin\p2fd.exe tx p2fprivacy send <получатель> 50up2f --anonymous ...(флаги как выше)

4. Заявка в валидаторы (PoW + KYC + железо):
   bin\p2fd.exe tx p2fpow apply-validator <kyc-хеш> <nonce> 8 ^
     --cpu 16 --ram-mb 65536 --disk-gb 2000 --net-mbps 10000 ...(флаги как выше)

5. Штраф валидатора (authority):
   bin\p2fd.exe tx p2fpenalty report-violation <адрес> downtime "причина" ...(флаги как выше)

ДЕМО-ВИЗУАЛИЗАЦИЯ (ОТДЕЛЬНОЕ ОКНО, ДЛЯ ЖЮРИ)
------------------------------------------------------------------------------------
В папке 5-ДЕМО лежит P2F-MVP-Демо.exe — интерактивная визуализация
блокчейна: сеть валидаторов, распространение блоков, кворум 2/3+1,
адаптивный PoW с живым перебором, скорость транзакций, анонимный режим,
майнинг CLANDAI. Два клика: «Запустить сеть» -> «Симуляция MVP ×3».
Подробности в 5-ДЕМО\README.txt. Проверка без окна:
   P2F-MVP-Демо.exe --selftest
